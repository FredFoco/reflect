## 🎯 In 30 Seconds

**Reflect** is a **journaling app** that tracks your emotional state and gives you insights.

- 📝 Log: Mood, energy, anxiety daily
- 📊 Analytics: Weekly trends, charts, insights
- 🔍 Search: Find entries by keywords/tags
- 🤖 AI: Get weekly reflections
- 🎨 Beautiful: Calm, zen design

## 🚀 Get It Running (2 Minutes)

```bash
# 1. Install
pip install -r requirements.txt

# 2. Run
export FLASK_APP=app.py
python3 -m flask run --host=127.0.0.1 --port=5001

# 3. Open browser
http://127.0.0.1:5001

# 4. Login
```
